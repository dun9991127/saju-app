# 나의 사주 명식

생년월일시를 넣으면 사주 원국표(천간·지지·십성·지장간·12운성·12신살·신살), 쉬운 말 사주 총론, 일간·주간·월간·연간·대운 운세, 일진 달력을 보여 주는 만세력 웹앱입니다.

- 설치 없이 브라우저에서 바로 쓰고, 휴대폰에서 "홈 화면에 추가"하면 앱처럼 설치됩니다(인터넷 없이도 열림).
- 입력한 정보는 보는 사람의 기기 안에서만 계산·저장되고 어디로도 전송되지 않습니다.
- 절기: 천문 계산(1900~2100년, 분 단위), 음력: 한국천문연구원 기준(1900~2050년).

## 다시 만들기
`source/` 안의 파일을 고친 뒤 `node source/build.js`를 실행하면 `source/index.html`과 `source/dist-app/`이 새로 만들어집니다. `dist-app/` 안의 파일을 저장소 맨 위로 복사하면 됩니다.
